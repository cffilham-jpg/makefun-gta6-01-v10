Lena Marín runs jobs across six districts in an original coastal city. Drive the Falcon GT, pick up a motorcycle, follow the radio crew through ten chapters, and build respect to unlock gear. Built for [make.fun](https://make.fun).

Run `node serve.ts` and open `http://localhost:8080` in desktop Chrome. The game serves all assets locally.

| Key | Action |
| --- | --- |
| WASD or arrows / Space | Walk, drive, or use the handbrake |
| E | Enter or leave the nearest vehicle |
| F or mouse / Q / 1–6 | Fire, crouch, select a weapon |
| Z / X / C | Call Reyes, Tomás, or Inés |
| J / V / K / L | Taxi, vigilante, race, or delivery |
| B / R / T | Supply shop, repair, or tune the radio |
| M / Esc | Story ledger or pause and save |

The four queries in `shots.json` open the pursuit, shootout, rainy marina and story ledger scenes.
